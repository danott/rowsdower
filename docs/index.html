ROWSDOWER!

Zap any page on the internet.

The crew of the Satellite of Love deserves a fair shot at any page on the internet. rowsdower puts their silhouette at the bottom of yours. One file, zero dependencies.

Install

Import it straight from a CDN:

<script type="module">
  import rowsdower from "https://unpkg.com/rowsdower"
  rowsdower()
</script>

Or use a plain old script tag, like it's the good old days. It sets a global rowsdower and runs all the way back to IE8. Download rowsdower.global.js to vendor it. 

<script src="https://unpkg.com/rowsdower/rowsdower.global.js"></script>
<script>
  rowsdower()
</script>

Or add it to your project:

npm install rowsdower
import rowsdower from "rowsdower"
rowsdower()

Cleanup

rowsdower() returns a function that removes the crew. That's what the button at the top of this page uses.

That's all any framework needs: call rowsdower() when your component mounts, and call the function it returns when it unmounts. Importing it is safe during server rendering, since it doesn't touch the DOM until you call it.

Appending anywhere

Pass an element to mount the crew somewhere other than document.body. The crew is position: fixed, so give the container a transform (or contain: layout) to keep them inside it.

Styling

Data attributes on the elements make handy CSS selectors.

Dark mode

The crew is a black silhouette, the way it looks against the movie screen. On a dark page, backlight them with a drop-shadow. This page does exactly that when your system is in dark mode. 

@media (prefers-color-scheme: dark) {
  [data-rowsdower-chairs] {
    filter: drop-shadow(0 0 1px rgb(255 255 255 / 0.9))
      drop-shadow(0 0 10px rgb(255 240 210 / 0.5));
  }
}

Wait, what?

“Rowsdower” is a reference to Zap Rowsdower, the protagonist of The Final Sacrifice, experiment #910 of Mystery Science Theater 3000.
